# Alien Wars Tower Defence

Mars'taki Nova Üssü'nü uzaylı sürüsüne karşı savunduğun, telefon için tasarlanmış bir kule savunma oyunu. Tasarım ve yol haritası için `CLAUDE.md` dosyasına bak.

## Çalıştırma

```bash
npm install
npm run dev      # yerel sunucu (telefondan aynı ağdaki IP ile açılabilir)
npm run build    # dist/ klasörüne çevrimdışı çalışan derleme
```

Klavye kısayolları: `1–4` kule kur, `U` yükselt, `S` sat, `Boşluk` dalgayı başlat, `F` hız, `Esc` seçimi kaldır.
